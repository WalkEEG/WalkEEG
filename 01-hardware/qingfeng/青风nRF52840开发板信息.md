# 青风（青云）nRF52840 开发板信息速查

> 整理自本仓库 `01-hardware/qingfeng/` 下的原理图：`52840core.pdf`（核心板）、`840底板1.pdf`、`840底板2.pdf`。
> 板卡厂商：青风电子（论坛 qfv8.com），例程中称"青云 nRF52840 蓝牙开发板"。
> 整理日期：2026-11-02。引脚以**原理图网络标签**为准；原理图未标注的模块座引脚已单独注明。

---

## 1. 板卡概述

- **结构**：核心板（`52840core.pdf`，3 页，2018-11-18）+ 底板两张图（`840底板1.pdf` / `840底板2.pdf`，2018-11-06）。
- **主控**：nRF52840-**QIAA**（aQFN73，7×7 mm）。
- **底板资源**：4× LED、4× 独立按键 + 复位键、蜂鸣器、CH340 USB 串口、nRF52840 原生 USB、W25X80 SPI Flash、MicroSD 卡座、LIS3DH/OLED1 模块座、OLED2 座、MPU6050 座、WIFI 模块座、NFC 天线座、触摸模块座、光敏电阻、DHT11 座、继电器接口（JDQ）、CR2032 备份电池。
- **供电**：USB 5V → AMS1117-3.3；核心板可用 VDD_HV（高压模式）或 VDD_nRF（3.3V）供电。

---

## 2. 芯片规格（nRF52840-QIAA）

| 项目 | 规格 |
|---|---|
| CPU | Cortex-M4F @ 64 MHz（带 FPU/DSP） |
| 存储 | **1 MB Flash / 256 KB RAM** |
| GPIO | 48 个（P0.00~P0.31 + P1.00~P1.15） |
| 无线 | BLE 5.0（1M/2M/Coded PHY）、IEEE 802.15.4（Thread/Zigbee）、2.4 GHz 私有协议、NFC-A |
| USB | USB 2.0 Full-Speed（12 Mbps），原生 D+/D- |
| 串口 | **2× UARTE** |
| SPI/TWI | 4× SPIM/SPIS、2× TWIM/TWIS；**QSPI**（可接外部 Flash） |
| 其他外设 | I2S、PDM、4× PWM、8 通道 SAADC、2× RTC、比较器、温度传感器 |
| 供电 | 1.7~5.5 V（VDDH 高压模式），内置 DC-DC |
| 封装 | aQFN73（QIAA），与 nRF52833/nRF52832 **不兼容**（引脚/封装均不同） |

> 与 nRF52833 对比：Flash 1 MB（52833 为 512 KB）、RAM 256 KB（52833 为 128 KB），且 52840 多出 QSPI、USB、802.15.4。

## 3. 核心板

### 3.1 关键器件

| 项目 | 规格 / 器件 |
|---|---|
| MCU | nRF52840-QIAA（aQFN73） |
| 高速晶振 | X1：32 MHz（C1/C2 = 12 pF） |
| 低速晶振 | X2：32.768 kHz，接 **P0.00/XL1、P0.01/XL2**（C17/C18 = 12 pF） |
| 射频匹配 | ANT → L1 3.9 nH、C3 1.0 pF、L3 15 nH、C4 1.0 pF、C8 820 pF、C9 1.2 pF（C22/C23 N.C.） |
| DC-DC | L2 10 µH（DEC4）、L4 10 µH（DCCH），C6/C19/C20/C21 = 4.7 µF |
| 电源网络 | VDD_nRF（3.3 V）、VDD_HV（高压输入）、VBUS_nRF（USB VBUS） |
| 调试 | SWD：SWDCLK / SWDIO；P0.18/RESET |
| 引出 | P1 / P2：2×14 双排针（见 3.2） |

> ⚠️ P0.00 / P0.01 在核心板上默认接 32.768 kHz 晶振；要把它们当 GPIO 或 I2C 用，需先确认/拆除 X2。

## 4. 底板外设与引脚映射（重点）

### 4.1 板载基本外设

| 外设 | 信号 | 引脚 | 说明 / 来源 |
|---|---|---|---|
| LED1 / LED2 / LED3 / LED4 | — | **P0.13 / P0.14 / P0.15 / P0.16** | 低电平点亮（LED 阴极接 GPIO，阳极经 220R 到 VCC3.3）；R2/R3/R5/R6 = 220R |
| 按键 BUTTON1 / BUTTON2 | — | **P0.11 / P0.12** | SW1/SW2，按下拉低；10k 上拉（R15，底板2） |
| 按键 BUTTON3 / BUTTON4 | — | **P0.24 / P0.25** | SW3/SW4，按下拉低（底板2） |
| 复位键 REST | P0.18/RESET | **P0.18** | REST1 + 10k 上拉 |
| 蜂鸣器 BEEP | BEEP | **P0.27** | R18 1k → Q1(2N3904) → LS1(Bell)；R20 10k 基极下拉 |
| USB 串口（CH340） | TX / RX / RTS / CTS | **P0.06 / P0.08 / P0.05 / P0.07** | U1=CH340，12 MHz 晶振；`TXD`→P0.08、`RXD`→P0.06 |
| nRF 原生 USB | D+ / D- / VBUS | P2-26 / P2-25 / VBUS_nRF | USB2 座，PRTR5V0U2X ESD 保护，磁珠 FB1/FB2 |
| SPI Flash | SCK / MOSI / MISO / CS | **P0.23 / P0.20 / P0.21 / P0.22** | U2 = W25X80（原理图标注），nHOLD/nWP 经 R22 10k 上拉 |
| MicroSD 卡座 | SD_CS / SCK / MOSI / MISO | **P0.19** / 共用 P0.23 / P0.20 / P0.21 | U3；与 Flash 共用 SPI 总线，SD_CS 独立 |
| 光敏电阻 | AD | **P0.04 / AIN2** | D1(Photo Sen) + R4 10k，SAADC 采样 AIN2 |
| 触摸模块 | TK（OUT） | **P0.26** | JR1 6 脚模块座（OUT/GND/S0/SHH/VDD/STG），C14 22 pF、R23 1k |
| 温湿度（DHT11 类） | WS | **P1.08** | P5 模块座（1 GND / 2 WS / 3 VCC3.3） |
| 继电器接口 | JDQ | **P1.09** | P11 第 23 脚 |
| 电源 | — | — | AMS1117-3.3、USB1(5V)、S1 电源开关、CR2032 备份 |

### 4.4 外部杜邦排针 P12 / P13（唯一可外接）

P12 与核心板 P1 一一对应（1~26 脚），P13 与核心板 P2 一一对应（1~26 脚），没有 P1/P2 的 27/28 电源脚；供电和地请从底板电源排针取。接线时按 3.2 的表同脚号对齐即可。

## 6. 软件与开发环境

| 项目 | 内容 |
|---|---|
| 官方例程 | 随板网盘资料（nRF5 SDK 17 / Keil），本仓库未收录 |
| Zephyr / NCS | 板级定义用 **`nrf52840dk/nrf52840`**（pca10056）即可跑，外设脚按本表覆盖 |
| 调试/烧录 | J-Link（SWDCLK/SWDIO）+ P0.18 复位 |
| 串口 | 板载 CH340：TX=P0.06、RX=P0.08（115200 8N1） |
| USB | nRF 原生 USB 可做 CDC/Bootloader，D+/D- 已引出到 P2 25/26 |

### 本仓库（WalkEEG）已有的接线约定

- `02-firmware/boards/nrf52840dk_nrf52840.overlay`：
  - NUS 物理串口：**P0.13 = TX、P0.12 = RX**（P12 第 25/26 脚），同时禁用了默认的 `led0` 与 `button1`；
  - AD8232：**AIN0 = P0.02**（P13 第 8 脚），增益 1/6；
  - ADS1293（SPI1）：**SCLK=P1.00（P12-12）、MOSI=P1.01（P12-11）、MISO=P1.02（P12-8）、CS=P1.03（P12-7）、DRDY=P1.04（P12-6）、RESET=P1.05（P12-5）**；GND/3V3 从底板电源排针取。CJMCU-1293 这类只有 9 脚的模块没有 RST，P1.05 不接，固件走 CONFIG=0 软复位。
- 注意：P0.12/P0.13 在本开发板上原本是 **BUTTON2 / LED1**，用 UART 时需像现有 overlay 一样禁用对应外设。

## 7. 注意事项（重要）

1. **P0.00 / P0.01 默认接 32.768 kHz 晶振**（核心板 X2）。做 GPIO 或 I2C（如 MPU6050 座的 SCL/SDA）前先确认晶振是否焊接/需要拆除。
2. **P0.09 / P0.10 = NFC1 / NFC2**：接 NFC 天线座 P3；不接天线时可作普通 GPIO，但注意 300 pF 电容和 0R 跳线。
3. **P0.18 = RESET**，板上已有复位键，勿再当普通 IO 使用。
4. **LED1~4 = P0.13~P0.16**，低电平点亮（灌电流），高电平熄灭。
5. **按键 = P0.11 / P0.12 / P0.24 / P0.25**，低有效，板上 10k 上拉。
6. **BEEP = P0.27**，经 2N3904 驱动，高电平响。
7. **Flash 与 SD 卡共用 SPI**：SCK=P0.23、MOSI=P0.20、MISO=P0.21；Flash_CS=P0.22、SD_CS=P0.19，同一时刻只能选一个片选。
8. **CH340 串口占用 P0.05~P0.08**，其中 P0.05/P0.07 同时是 AIN3/AIN5 的复用脚。
9. **P1 口分工**：P1.02~P1.07 = WIFI 座，P1.08 = WS（DHT11），P1.09 = JDQ，P1.10~P1.15 = LIS3DH/OLED1 座；这些功能与 P10/P11 排针是同一网络，插模块时不要与其他用途抢脚。
10. **OLED2 与 MPU6050 座共用 P0.28~P0.31**（RST/MOSI/SCK/INT），同时插两个模块会冲突。
11. **与青风 nRF52833 板不通用**：LED/按键数量、串口芯片（本板 CH340）、引脚分布都不同，代码与接线不能照搬（52833 板资料见 `BALANX2_FIRMWARE/青风nRF52833开发板信息.md`）。
12. 原理图中模块座个别脚（P14 的 1/2 脚、P6 的 2 脚、P7 的 2~4/8 脚）未标网络名，实际接线以 PCB 丝印/实物为准。
